# 🎮 TicTacX

A modern and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript** as part of my **Web Development Internship at Prodigy InfoTech**.

## ✨ Features

* 🎮 Player vs Player Mode
* 🤖 AI Mode with Multiple Difficulty Levels
* 🌙 Dynamic Theme Switching
* 🏆 Score Tracking System
* 🔊 Sound Effects & Music Controls
* 📱 Responsive Design
* ✨ Smooth Animations and Modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
